# ROADMAP

## 1단계: 데이터 정규화
- PDF 원문 문제를 JSON으로 정리
- 문제 번호, 보기, 정답, 해설(선택) 필드 고정
- 660문제 전체를 한 형식으로 통합

## 2단계: 뷰어 운영
- 화면에서 문제/보기 즉시 확인
- 문제 이동(이전/다음/직접 번호 이동)
- 10문제 단위 학습 배치 사용

## 3단계: 출력 포맷 고정
- 문제 인용 ↔ 정답 인용만 사용
- 정답 연결 2~3줄 유지
- 문제별 구분선(---) 고정

## 4단계: 생산성 자동화
- 10문제 단위 자동 템플릿 생성
- 서비스명 영어 원문 유지 검사
- 출력 규칙 위반 자동 점검

## 메모
문제 정답 검증은 요청 시에만 수행하고 기본은 제공된 Answer를 그대로 사용합니다.
