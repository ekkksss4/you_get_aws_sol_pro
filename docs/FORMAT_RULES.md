# 문제 정리 출력 규칙

목적
- 덤프/문제은행 복습 및 암기
- 문제 문장과 정답 요소를 직접 연결
- 불필요한 장문 요약/오답 분석 제외

출력 기본 형식
---

### Q번호 / Answer: 정답

**문제 인용 ↔ 정답 인용**

① "문제에서 정답 판단에 필요한 핵심 문장"
→ "정답 선택지에서 직접 연결되는 핵심 요소"

② "문제의 다른 핵심 조건"
→ "그 조건을 해결하는 AWS 서비스/기능/구성"

③ "필요 시 추가 핵심 조건"
→ "대응하는 정답 부분"

**정답 연결**
문제 핵심 조건이 왜 해당 AWS 서비스/구성으로 이어지는지 2~3줄로 작성.
시험장에서 바로 떠올릴 수 있는 암기 문장 형태를 우선.

---

세부 규칙
1. 한 번에 최대 10문제씩 정리
2. 각 문제 시작은 반드시 다음 형식 사용
   - ### Q번호 / Answer: 정답
3. 항목은 정확히 다음 2개만 사용
   - 문제 인용 ↔ 정답 인용
   - 정답 연결
4. 핵심 규칙
   - 문제 조건과 정답 요소를 반드시 ① ② ③ 형태로 직접 매칭
5. 문제 인용
   - 제공된 원문에서 정답 판단에 필요한 문장/구절만 사용
   - 가능한 원문 표현 유지
6. 정답 인용
   - 제공된 정답 선택지에서 서비스명/기능/구성/액션만 짧게 사용
7. 매칭 수
   - 보통 문제당 2~4개, 억지 개수 맞추지 않음
8. 하나의 조건이 여러 구성과 연결되면 화살표를 추가로 사용 가능
9. 정답 연결
   - 연결 이유만 2~3줄로 작성
   - 오답 선택지 설명 금지
10. AWS 서비스/기능명은 영어 원문 유지
11. 정답은 문제의 Answer를 기준으로 유지
12. 문제별 구분선 --- 사용
